Noah Scott

Noah Scott writes Calcupine's project guides. Every guide starts from what homeowners are searching for right now, is researched from manufacturer data, university extension advice and building standards, and is checked against our calculators before it goes live.

How the guides are checked

Every number in a guide is worked out with the same formulas as our calculators, which are tested against hand-worked examples. Sources are linked at the end of each guide. See how we calculate, or report a mistake.
